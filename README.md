# 📈 LS증권 Open API 기반 기관·외국인 수급 & EMA 스크리닝 시스템

야간시장(NXT) 마감 이후 **매일 밤 21:05(KST)** GitHub Actions에서 자동으로 LS증권 Open API를 호출하여 **일봉 차트(수정주가 기준) + 지수이동평균(EMA 5, 20, 60, 120, 240)** 및 **투자주체별 수급(수량·금액)**을 수집하고, **Supabase 클라우드 DB** 업데이트와 **텔레그램 알림**을 수행하는 시스템입니다.

---

## 🎯 핵심 스크리닝 및 시가총액 산출 기준

1. **분석 대상 유니버스**:
   * 코스피(KOSPI) + 코스닥(KOSDAQ) 통합 보통주
   * **시가총액 700억 원 이상** & **최근 20일 평균 거래대금 20억 원 이상**
   * 제외 대상: ETF, ETN, ELW, 스팩(SPAC), 우선주, 리츠, 인버스/레버리지
2. **시가총액 및 유니버스 산출 주기 (부하 최소화 하이브리드)**:
   * **정기 산출**: **최초 1회(DB 미구축 시) + 매년 3·6·9·12월 첫 거래일**에 `t1444`(시가총액 상위) 및 `t8436`(보통주 마스터)를 결합해 시가총액 ≥ 700억 종목과 상장주식수(`shares`)를 산출하여 저장합니다.
   * **일일 증분 + 급등주 자동 편입**: 평일 일일 배치(`daily`)에서는 저장된 유니버스 종목만 조회하고 `상장주식수 × 당일종가`로 부하 없이 시가총액을 자동 갱신하며, 당일 거래대금 상위(`t1463`, 2회 호출·1.3초 소요)를 함께 체크해 분기 중 급등 주도주를 자동 편입합니다.
3. **순수 기관(`real_inst`) 정의**:
   * 단기 차익·LP 물량이 많은 **금융투자 제외**
   * **`순수 기관 = 투신 + 사모펀드 + 연기금 + 보험 + 기타금융 + 은행`**
4. **핵심 정렬 및 포착 지표**:
   * **`거래량 대비 순수기관 순매수 비중(%) = (기간 순수기관 순매수 수량 ÷ 기간 거래량) × 100`** (기본 10% 이상, 비중 높은 순 정렬)
   * 당일(1일), 3일 누적, 5일 누적, 10일 누적 및 사용자 지정 N일 누적 지원
5. **기술적 분석 지표**:
   * 수정주가(`sujung=Y`) 기준 일봉 OHLCV 및 **5일, 20일, 60일, 120일, 240일 지수이동평균(EMA)**

## 🧪 실행 및 4단계 데이터 검증 명령어

```bash
# 1. 일일 자동 배치 실행 (최초 실행 시 자동으로 초기 유니버스 구축)
python3 run_daily_screener.py --mode daily

# 2. 상위 30종목 빠른 샘플 적재 테스트
python3 run_daily_screener.py --mode daily --max-stocks 30

# 3. Supabase 적재 데이터 4단계 정합성 검증 리포트 출력
python3 run_daily_screener.py --mode verify
```
